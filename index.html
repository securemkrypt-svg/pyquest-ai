Lab 4 • RAM Internals

Stack vs. Heap Memory & PVM

See how Python variables point to objects in RAM via references.

Stack (Names)
a→ 0x7F1A
b→ 0x7F1A
Heap (Objects)
id: 0x7F1A | refcnt: 2
list: [1, 2, 3]

Reference Counting: Both a and b on the Stack point to the same Heap list (refcnt = 2). When refcnt hits 0, Python's Garbage Collector frees the RAM!
